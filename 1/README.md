# Oven & Bloom Bakery Website

A responsive, multipage HTML/CSS/JavaScript template for a local bakery and custom cake studio. No build step or framework is required.

## Quick start

From this folder, run a local static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

Opening the HTML files directly also works for most features, but a local server is recommended for accurate link, map, and browser testing.

## Included pages

- `index.html` — warm retail-led home page
- `index1.html` — editorial cake-atelier home page
- `pages/products.html` — occasion filters and product catalogue
- `pages/custom-orders.html` — detailed custom-cake brief
- `pages/pricing.html` — pricing tiers and live estimator
- `pages/delivery.html` — zones, postcode demo, and map
- `pages/contact.html` — same-day enquiry and bakery location
- `pages/about.html` — brand story, values, and team
- `pages/services.html` — events, gifting, and catering
- `pages/blog.html` — journal listing
- `pages/privacy.html`, `pages/terms.html` — legal templates
- `pages/signin.html`, `pages/signup.html` — account UI placeholders
- `pages/404.html`, `pages/coming-soon.html` — utility pages

## Before launch

1. Replace all `example.com` URLs, example email addresses, phone numbers, and the demo address.
2. Connect verified form, newsletter, payment, booking, analytics, and authentication providers.
3. Replace remote demo photography with licensed, optimized local WebP/AVIF files.
4. Review prices, delivery areas, allergens, terms, and privacy language.
5. Update `sitemap.xml`, `robots.txt`, canonical URLs, and JSON-LD.
6. Run accessibility, performance, browser, and form-submission checks on the final host.

Detailed setup and customization notes are in `documentation/guide.md`.
