# DriveWay Driving School Website

A responsive, accessible multipage driving-school template built with HTML, CSS, and vanilla JavaScript. The public landing page, student dashboard, courses, instructors, vehicles, fees, authentication, policy, and utility pages are included.

## Quick start

Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Main entry points

- `index.html` — reference-matched primary landing page
- `index1.html` — alternate overview home page
- `pages/dashboard.html` — interactive student portal
- `pages/courses.html` — two-wheeler, four-wheeler, and refresher programs
- `pages/instructors.html` — instructor profiles
- `pages/vehicles.html` — training fleet
- `pages/fees.html` — course pricing
- `pages/signin.html` / `pages/signup.html` — validated authentication demos

## Features

- Mobile-first layouts across phone, tablet, desktop, and large screens
- Light/dark theme with automatic system preference and saved choice
- Full left-to-right/right-to-left layout toggle
- Keyboard focus states, skip links, semantic structure, reduced-motion support, and accessible labels
- Client-side form validation with clear inline errors
- Interactive lesson slots, booking feedback, and printable progress report
- Local generated hero image plus optimized WebP version

Full setup, customization, page structure, credits, support details, and the changelog are in the `documentation` directory.
